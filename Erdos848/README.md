# Erdos848 (Lean 4 + Mathlib)

A complete Lean formalisation of the computer-assisted proof of Erdős Problem #848 (the manuscript is `../paper/erdos848.pdf`; the detailed written proof is `../supplement/proof.md`).

**Main theorem** (`Erdos848/Final.lean`):

```lean
theorem Erdos848.erdos848 : ∀ N, Statement N
-- Statement N := ∀ A ⊆ Finset.Icc 1 N, Admissible A → A.card ≤ c7 N
-- Admissible A := ∀ a ∈ A, ∀ b ∈ A, ¬ Squarefree (a * b + 1)
-- c7 N := (N + 18) / 25 = #{n ≤ N : n ≡ 7 (mod 25)}
```

It also contains `erdos848_max'` (the maximum is exactly `c7 N`) and `erdos848_formalConjectures` (the formulation of the formal-conjectures project). There is no `sorry`.

## Axioms

`#print axioms Erdos848.erdos848` lists only `propext`, `Classical.choice` and `Quot.sound`. Every computation is written as `decide +kernel` and evaluated by the Lean kernel; **no `native_decide` is used**, so neither the Lean compiler, the runtime, nor any external program has to be trusted. The programs that generate the data (`../code/kernel/`) need not be trusted either: data is only used after the kernel has checked it, and the soundness of every checker is proved in Lean.

## Building

```bash
export PATH=$HOME/.elan/bin:$PATH
lake exe cache get
lake build
```

The kernel checks take about 5 CPU hours in total (about 1 hour on a machine with 20 cores and 62 GB of memory). Peak memory per module: at most 3.5 GB for an interval module (`K2/J*.lean`), at most 9.3 GB for a colouring window (`KColW/K*.lean`), at most 7.6 GB for the rest. `lake build` compiles independent modules in parallel, by default one per core; limit the parallelism if memory is short.
